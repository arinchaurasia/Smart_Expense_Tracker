# 💳 BudgetMind: Smart Expense Tracker

BudgetMind is a modern, AI-powered personal expense management platform that enables users to track daily expenses, set budgets, auto-extract items from receipts using Gemini Vision, and receive AI-driven financial recommendations.

## ✨ Features

- **🔒 Google Authentication**: Secure sign-in with Google via Firebase Auth to protect user data and ensure strict user-data isolation.
- **💰 Expense Tracking**: Add, categorize, and delete expenses in real time.
- **📄 AI Receipt Scanner**: Upload receipt images, PDFs, or CSV files — Gemini AI auto-reads amounts, vendors, and categories.
- **📊 Monthly Insights**: Category-wise expense breakdown with visual progress bars.
- **🎯 Budget Management**: Set personalized monthly budgets with dynamic progress status alerts.
- **⚡ AI Financial Advisor**: Integrated Gemini AI provides custom daily limits and saving advice.

## 🚀 Tech Stack

- **Frontend**: HTML5, CSS3 (Poppins typography, glassmorphism UI), JavaScript (ES6)
- **Backend & Database**: Firebase Realtime DB / Firestore & Firebase Auth
- **AI Engine**: Google Gemini API via Vercel Serverless Functions
